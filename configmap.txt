A ConfigMap stores non-sensitive configuration separately from the application image.

apiVersion: v1
kind: ConfigMap
metadata:
  name: app-config
data:
  APP_NAME: InternetBanking
  APP_ENV: development



Apply:
kubectl apply -f configmap.yml
kubectl get configmaps
kubectl describe configmap app-config


Example of using it in a Pod:

apiVersion: v1
kind: Pod
metadata:
  name: config-demo
spec:
  containers:
    - name: nginx-container
      image: nginx:stable
      envFrom:
        - configMapRef:
            name: app-config



Apply the Pod after creating the ConfigMap:
kubectl apply -f config-demo.yml
kubectl exec config-demo -- printenv APP_NAME
